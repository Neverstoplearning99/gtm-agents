# START HERE - How Obsidian Works

Read this once. Keep it in your vault. Delete nothing else until you read this.

---

## 1. What is a vault

A vault is a folder on your Mac. That is the whole thing.

- Filing cabinet = vault
- Pieces of paper = your notes
- The desk you write at = Obsidian app

Your notes are plain text files. You own them. No cloud lock-in.

---

## 2. Why it looks empty right now

Because it is brand new. We built empty drawers with labels. You fill them as you work.

Those "index" notes scattered around? Noise from a default setting. Safe to delete. Ignore them.

---

## 3. The only 5 things you need to know

### New note
Click the pencil-and-paper icon, top left. Or press Cmd + N.

### Find anything
- Cmd + O = jump to any note by name (fast)
- Cmd + Shift + F = search every word in every note

### Write
Notes use simple markdown. You only need these:

```
# Big heading
## Smaller heading
- bullet point
**bold**
[[Note Name]]  = link to another note
```

### Link notes together
Type two square brackets: [[ ]]
Start typing a note name. Pick it. Now the two notes are connected.
This is Obsidian's superpower. Notes link, not just sit in folders.

### See the web of links
Click the graph icon (looks like connected dots). Shows how your notes connect. Cool, not essential.

## 4. How to actually think about it

Do NOT organize first. You will freeze.

Capture first, sort later.

- Dump every new thing into 00-Inbox
- Once a week, drag things into the right folder
- That is it

A messy inbox beats a perfect empty system.

## 6. How this connects to Claude and Codex

The vault is one shared brain. Both Claude and Codex read and write to the same folder.

The flow:
1. Work in any AI tool
2. Say the trigger: "Pack handoff for [target]" or #obsidian
3. It writes a note into 01-Knowledge-Transfer
4. The next tool reads that note and picks up where you left off

One brain. Both halves use it. Nothing gets lost.
